# Arquiteto de Operações

Design System fundador e infraestrutura digital da categoria profissional **Arquiteto de Operações**.

## Hierarquia estratégica

1. **Mudança de mercado** — Uma nova capacidade profissional está emergindo.
2. **Categoria profissional** — Arquiteto de Operações.
3. **Disciplina** — Arquitetura Operacional.
4. **Transformação entregue** — Operação Previsível.
5. **Fundador e principal voz** — Leonardo Brasil.

## Versão atual

**Design System Fundador v0.1.1 — Reorientação Estratégica**

Esta versão reposiciona a profissão como centro da narrativa, preservando Arquitetura Operacional como a disciplina que sustenta a prática e Operação Previsível como o resultado entregue.

## Arquivos principais

- `index.html` — landing page principal
- `styleguide.html` — guia visual navegável
- `DESIGN_SYSTEM.md` — documentação estratégica e visual
- `tokens.json` — tokens e metadados estruturados
- `CHANGELOG.md` — histórico de alterações
- `API_CONTRACT.md` — contrato inicial para formulários e integrações
- `admin.html` — visualização local dos registros
- `privacy.html` — política de privacidade inicial

## Execução local

O projeto é estático. Abra `index.html` diretamente no navegador ou execute um servidor local:

```bash
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080`.
